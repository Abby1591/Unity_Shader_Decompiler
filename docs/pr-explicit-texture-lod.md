# Keep explicit zero texture LOD explicit

Do not replace SampleLevel(..., 0) with Sample(...): implicit derivatives can select a different mip. Remove the transformation and add a regression checking that the explicit LOD survives optimization.

Validation: 52 C# tests and all four existing PicaVoxel extraction/decompilation tests pass. C# tests use an en-US default culture; the upstream fr-FR golden-output failure is addressed independently by the numeric-formatting PR. The golden output was regenerated by the emitter for this change only; existing comparison assertions are unchanged.

This branch is based directly on upstream `1850608`; it does not include the other review branches. No proprietary fixtures or machine-specific paths are added.
