# Preserve values across conditional control flow

Values assigned inside a conditional could be referenced outside their declaration scope, and phi copies could run before a nested join. Declare branch-written values in the enclosing scope and place copies after the closing conditional. Tests cover reads after an if and copies after a nested join; they do not exhaust every loop/switch combination.

Validation: 53 C# tests and all four existing PicaVoxel extraction/decompilation tests pass. C# tests use an en-US default culture; the upstream fr-FR golden-output failure is addressed independently by the numeric-formatting PR. The golden output was regenerated by the emitter for this change only; existing comparison assertions are unchanged.
