# Preserve vector lanes in casts and dot products

Use the operand width for numeric casts and the instruction width for dot products. Keep the selected lanes when recognizing normalization; a three-lane expression must not read the fourth lane.

Validation: 54 C# tests and all four existing PicaVoxel extraction/decompilation tests pass. C# tests use an en-US default culture; the upstream fr-FR golden-output failure is addressed independently by the numeric-formatting PR. The golden output was regenerated by the emitter for this change only; existing comparison assertions are unchanged.
